# Benchmarks

Reports from `cuteafd bench` (profiles other than the basic one run when asked). Each directory holds `report.svg`, `report.json` and the share card; `cuteafd bench publish` rebuilds this index and the root README's table.

Prefill reports without `prompt_content: "realistic-v1"` used synthetic filler.
New prefill prompts use fixed repository code, technical prose and reviewed
agent/tool transcripts; the content change shifts prefill numbers, so these
are not like-for-like historical comparisons. Decode and agentic-session
workloads are unchanged.

### v5 Retirements

The v5 launch matrix pins measured historical cards in its `retired` list:
all NVFP4 cards, Step-5 FP8, GLM Flash tr3, and the previously retired layouts.
The published `current-matrix.json` and root README now pin passing v5 rc1
max cards, retain earlier measured cells until their replacement passes, and
include all 27 measured retirement pins. Entirely pending checkpoint rows
remain outside the table until their first passing report exists. GLM Flash
EXLR8 is withheld in all three columns: rc1 refuses its native vocabulary
arena names; fixed-build follow-up cards are pending.
New measured retirements are `v41-flash-reference-tp4`,
`v4-flash-reference-tp4`, `glm53f-exl3-5090` (K3.25 + Core FP8),
`glm53-exlr8-a8-max`, `qwen38-27b-bf16-min-nospec`, and
`qwen38-27b-fp8-min-nospec`. The unmeasured `v41-flash-max-fp8-reply` and
`v41-flash-max-nvfp4-reply` variants are also removed from the runnable v5
matrix; they have no published report to pin as a measured retired card.
Neither Step-5 FP8 nor Step-5 NVFP4 is scheduled. The v4 matrix remains the
historical recipe; new release launches use the v5 matrix.
